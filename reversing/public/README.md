- Vulnerability

RSA 암호 알고리즘을 사용하지만, 암호화 과정에서 사용된 공개키 $n$의 소인수인 $p$와 $q$가 공개되어 있거나 소인수분해가 매우 쉬운 작은 값으로 설정되어 있습니다. RSA의 안전성은 $n$을 소인수분해하기 어렵다는 점에 기반하는데, 인자값이 노출되어 있으면 비밀키 $d$를 즉시 계산할 수 있는 취약점이 존재합니다.

- Exploit

제공된 p와 q를 이용하여 오일러 파이 함수 값 phi(n) = (p-1)(q-1)을 구했습니다. 이후 공개키 e의 모듈러 역원을 계산하여 비밀키 d를 도출했습니다. 확보한 비밀키 d를 사용하여 out.bin에 저장된 암호문 블록들을 복호화함으로써 플래그를 획득했습니다.
