Secure Mail
https://dreamhack.io/wargame/challenges/92

- Vulnerability

비밀번호를 입력받아 메일 내용을 보호하는 기능에서 시도 횟수에 대한 제한(Rate Limiting)이 없고, 검증 로직이 클라이언트 측에서 이루어져 자동화된 공격에 노출될 수 있는 취약점이 존재합니다.

- Exploit

Selenium 라이브러리를 사용하여 브라우저를 자동화하고, 000000부터 999999까지의 모든 6자리 숫자 조합을 입력하는 브루트 포스 공격을 수행했습니다. 비밀번호가 틀렸을 때 나타나는 경고창의 발생 여부를 확인하여 올바른 비밀번호를 찾아냈으며, 최종적으로 잠금이 해제된 페이지에서 플래그를 획득했습니다.
