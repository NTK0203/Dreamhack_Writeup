https://dreamhack.io/wargame/challenges/23

- Vulnerability

사용자 입력값을 8바이트 단위 블록으로 나누어 특정 알고리즘으로 암호화한 뒤, 미리 저장된 데이터와 비교하는 검증 로직이 존재합니다. 암호화 과정에서 고정된 키('I_am_KEY'), S-box 치환, 그리고 비트 회전(Rotation) 연산이 사용되는데, 이 모든 요소가 바이너리에 노출되어 있어 알고리즘의 역산이 가능한 상태입니다.

- Exploit

바이너리 분석을 통해 파악한 암호화 로직을 바탕으로 역연산을 수행하는 복호화 스크립트를 작성했습니다. 암호화 시의 연산 순서를 뒤집고, ROR 5 연산을 ROL 5로, S-box 값을 이용한 가산 연산을 감산 연산으로 치환하여 복호화 함수를 구성했습니다. 이를 통해 암호화된 상태로 저장되어 있던 unkdata를 복호화하여 원본 플래그 문자열을 획득했습니다.
