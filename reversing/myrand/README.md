- Vulnerability

무작위 값을 생성할 때, 바이너리에 고정된 데이터 테이블(byte_4020)과 사용자 입력값을 이용한 커스텀 PRNG(의사 난수 생성기) 로직을 사용합니다. 로직과 초기 데이터를 알고 있다면 서버가 내놓을 모든 숫자를 완벽하게 예측할 수 있는 취약점이 존재합니다.

- Exploit

바이너리 분석을 통해 초기 데이터 테이블과 상태 변조 함수(sub_12f7)를 추출했습니다. 서버에 이름으로 "abcd"를 전달한 뒤, 로컬에서도 동일한 입력값으로 테이블을 변조하여 서버와 내부 상태를 동기화했습니다. 이후 변조된 테이블에서 순차적으로 유도되는 100개의 난수 값을 미리 계산하고, 각 라운드마다 서버의 패를 이길 수 있는 값을 전송하여 게임을 클리어하고 플래그를 획득했습니다.
