r-xor-t
https://dreamhack.io/wargame/challenges/901

- Vulnerability

사용자 입력값을 특정 알고리즘(ROT-13 변형, 문자열 반전, XOR 연산)으로 암호화하여 저장된 데이터와 비교하는 검증 로직이 존재합니다. 사용된 모든 연산이 단방향 암호화가 아닌 단순 치환 및 위치 변환이며, 비교 대상인 암호문이 바이너리에 노출되어 있어 역산이 가능한 취약점이 존재합니다.

- Exploit

바이너리 분석을 통해 암호화 순서를 파악하고 이를 역순으로 수행하는 복호화 스크립트를 작성했습니다. 
먼저 
1) 암호문 각 바이트를 3과 XOR 연산하고,
2) 리스트를 다시 역으로 바꾸고,
3) (val + 13) & 0x7F 연산의 역연산인 (val - 13) % 128을 수행했습니다.
이 과정을 통해 계산된 아스키 코드들을 문자열로 변환하여 원본 플래그를 복원했습니다.
