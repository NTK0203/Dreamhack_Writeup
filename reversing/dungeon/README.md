dungeon-in-1983
https://dreamhack.io/wargame/challenges/1212

- Vulnerability

각 스테이지마다 무작위로 주어지는 캐릭터 스탯값이 특정 메모리 주소의 각 바이트를 구성하며, 정해진 연산 규칙('A'는 +1, 'B'는 *2)을 조합하여 해당 주소값을 정확히 만들어내야 합니다.

- Exploit

출력되는 7가지 스탯을 각각 바이트 단위로 파싱하고 리틀 엔디언 형식으로 결합하여 대상 포인터 주소를 복원했습니다. 대상 주소값부터 시작하여 값이 짝수면 2로 나누고('B'), 홀수면 1을 빼는('A') 역산 과정을 거친 뒤, 도출된 문자열을 뒤집어 연산 경로를 생성했습니다. 이 과정을 10번 반복하여 플래그를 획득했습니다.
