hash-browns
https://dreamhack.io/wargame/challenges/98

- Vulnerability

입력값을 3바이트씩 나누어 MD5 해시로 변환한 뒤 미리 저장된 값과 비교하는 로직을 사용합니다. 해시 함수의 특성상 단방향성이지만, 해싱 대상인 문자열의 길이가 매우 짧아 브루트 포스를 통한 역산이 가능한 취약점이 존재합니다.

- Exploit

바이너리 분석을 통해 추출한 데이터들을 리틀 엔디언 형식의 128비트 MD5 해시 주소로 복원했습니다. 이후 3글자로 이루어진 모든 출력 가능 문자 조합에 대해 MD5 해시를 생성하고, 이를 추출한 목표 해시값들과 대조하여 각 청크의 원본 문자열을 알아냄으로써 전체 플래그를 복원했습니다.
