- Vulnerability

사용자 입력을 저장하는 버퍼의 크기보다 더 큰 데이터를 입력받을 때 발생하는 스택 버퍼 오버플로우 취약점이 존재합니다. 이를 통해 버퍼 뒤에 위치한 특정 변수의 값을 조작할 수 있습니다.

- Exploit

128바이트의 쓰레기 값을 입력하여 버퍼를 가득 채운 뒤, 그 뒤에 위치한 파일 경로 관련 변수를 "/home/bof/flag" 문자열로 덮어씌워 프로그램이 플래그 파일을 출력하도록 페이로드를 작성했습니다.
