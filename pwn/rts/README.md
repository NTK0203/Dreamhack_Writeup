Return to Shellcode
https://dreamhack.io/wargame/challenges/352

- Vulnerability

사용자 입력 시 입력 길이를 검증하지 않아 스택 카나리를 유출하고 리턴 어드레스를 덮어쓸 수 있는 스택 버퍼 오버플로우 취약점이 존재합니다. 또한 프로그램에서 버퍼의 시작 주소를 제공합니다.

- Exploit

첫 번째 입력을 통해 스택 카나리 값을 유출하고, 제공된 버퍼의 주소를 확인했습니다. 이후 두 번째 입력에서 버퍼에 쉘코드를 삽입한 뒤 유출한 카나리 값을 보존하고 리턴 어드레스를 버퍼의 시작 주소로 변조하여 쉘코드가 실행되도록 페이로드를 작성했습니다.
