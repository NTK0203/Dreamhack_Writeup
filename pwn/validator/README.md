- Vulnerability

특정 문자열 헤더와 바이트 배열 조건을 만족해야 하는 검증 로직 이후, 입력값의 길이를 제한하지 않아 스택의 리턴 어드레스를 변조할 수 있는 스택 버퍼 오버플로우 취약점이 존재합니다.

- Exploit

검증 조건을 만족하는 헤더와 데이터를 전송하여 버퍼를 채운 뒤 ROP 체인을 구성했습니다. 가젯을 통해 read 함수를 호출하여 쓰기 권한이 있는 BSS 영역에 쉘코드를 작성하고, 리턴 어드레스를 해당 BSS 주소로 변조하여 쉘코드가 실행되도록 페이로드를 작성했습니다.
