- Vulnerability

사용자 입력 과정에서 버퍼의 크기를 초과하는 데이터를 입력받아 메모리 주소를 유출할 수 있는 스택 버퍼 오버플로우 취약점이 존재합니다. 또한, 프로그램에서 제공하는 임의 주소 쓰기 및 메모리 해제 로직을 통해 함수 호출 흐름을 조작할 수 있습니다.

- Exploit

스택 버퍼 오버플로우를 통해 __libc_start_main 주소를 유출하고 libc 베이스 주소를 계산했습니다. 이후 임의 주소 쓰기 기능을 활용하여 __free_hook을 system 함수의 주소로 변조했습니다. 최종적으로 free 함수의 인자로 "/bin/sh" 문자열의 주소를 전달하여 쉘을 획득하도록 페이로드를 작성했습니다.
